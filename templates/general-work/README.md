# General Work Workspace

An all-purpose workspace with every Terminator capability enabled. Ideal for day-to-day knowledge work: research, writing, communications, scheduling, and data analysis.

## Folder Structure

```
inbox/      — Incoming items to process (emails, tasks, notes)
drafts/     — Work in progress
archive/    — Completed work
data/       — Datasets, CSVs, and databases
```

## Getting Started

1. Copy this template folder to your desired location
2. Open in your agentic IDE
3. Prompt: *"Set up Terminator in this workspace"*
4. Edit `.env` to add API keys for any channels you want to use

## What You Can Do

- **Research**: "Research the latest trends in AI agents and summarize findings"
- **Write**: "Draft a project proposal for the Q3 initiative"
- **Schedule**: "Remind me every Monday at 9am to check project status"
- **Communicate**: "Send a summary of today's work to my Telegram"
- **Analyze**: "Analyze the CSV in data/ and show me key patterns"
- **Automate**: "Set up a daily briefing chain that checks email and news"
