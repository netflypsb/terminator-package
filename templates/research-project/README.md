# Research Project Workspace

A research-focused workspace optimized for web research, data collection, note-taking, and report generation. Uses browser, memory, data, and file tools.

## Folder Structure

```
sources/    — Reference materials, PDFs, bookmarks
notes/      — Research notes and observations
findings/   — Synthesized findings and analysis
reports/    — Final reports and deliverables
```

## Getting Started

1. Copy this template folder to your desired location
2. Open in your agentic IDE
3. Prompt: *"Set up Terminator in this workspace"*

## Example Prompts

- *"Research the competitive landscape for AI code editors and save findings"*
- *"Read this URL and extract the key data points into notes/"*
- *"Analyze the CSV in sources/ and generate a findings report"*
- *"Compile all my notes into a comprehensive report in reports/"*
- *"Monitor this webpage daily for changes"*
