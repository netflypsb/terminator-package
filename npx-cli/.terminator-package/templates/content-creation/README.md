# Content Creation Workspace

A writing-focused workspace for blogs, articles, documentation, and content production. Uses memory to track style preferences, browser for research, and files for template rendering.

## Folder Structure

```
drafts/     — Work in progress
published/  — Final published content
assets/     — Images, diagrams, supporting files
research/   — Background research and reference material
```

## Getting Started

1. Copy this template folder to your desired location
2. Open in your agentic IDE
3. Prompt: *"Set up Terminator in this workspace"*

## Example Prompts

- *"Write a blog post about the future of autonomous AI agents"*
- *"Research this topic and create an outline for a 2000-word article"*
- *"Edit the draft in drafts/article.md for clarity and tone"*
- *"Remember my writing style: conversational, short paragraphs, use analogies"*
- *"Summarize this long document into a 300-word executive summary"*
