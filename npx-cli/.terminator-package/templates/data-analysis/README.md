# Data Analysis Workspace

A data-focused workspace for CSV analysis, SQL queries, statistical analysis, and report generation. Uses the data server for queries and analysis, files for processing, and memory to track findings.

## Folder Structure

```
raw-data/   — Original datasets (CSV, JSON, SQLite)
processed/  — Cleaned and transformed data
analysis/   — Analysis scripts and intermediate results
reports/    — Final reports and visualizations
```

## Getting Started

1. Copy this template folder to your desired location
2. Place your datasets in `raw-data/`
3. Open in your agentic IDE
4. Prompt: *"Set up Terminator in this workspace"*

## Example Prompts

- *"Read the CSV in raw-data/ and show me summary statistics"*
- *"Find correlations between columns A and B in the dataset"*
- *"Clean this data: remove duplicates, handle missing values, save to processed/"*
- *"Run a SQL query to find the top 10 customers by revenue"*
- *"Generate a report with key findings from my analysis"*
- *"Compare these two datasets and highlight differences"*
